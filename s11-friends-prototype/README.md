# S11 4秒試作

「僕はその通知を、目黒の自宅のソファで見た。」の38–42秒に相当する、映像方式確認用の独立ショットです。30 fps、1920×1080、120フレーム。ナレーションとBGMは含めず、動きと合成の評価に集中します。

## 構成

- 基準静止画、人物・植物を除いたクリーンプレート、人物、前景植物を画像生成で制作。
- Remotion側で部屋、夜景、窓枠、TV、TV光、ソファ、テーブル、人物の体幹・頭・腕・手とスマホ、スマホ光、前景植物を別レイヤーとして合成。
- 4秒間に横ドリー28 px、5.5%の寄り。夜景7 px、前景植物31 pxの相対移動で視差を作る。
- 呼吸、頭の小さな傾き、右腕と手の微動、TVとスマホの光、粒子とグレインを加える。

## 再現

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm render
pnpm qa
pnpm layers
```

成果物は `out/s11-four-seconds.mp4`、`out/s11-qa-sheet.png`、`out/s11-layer-sheet.png`。QAシートには基準静止画と開始・中間・終了フレームを並べています。
